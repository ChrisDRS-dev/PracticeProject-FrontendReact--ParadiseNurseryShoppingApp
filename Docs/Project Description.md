## Descripción del proyecto

  

For the final project, you built a shopping cart application for an online plant shop called **Paradise Nursery**.

  

The task involved creating a dynamic web application that allowed users to:

  

- Browse plants.

- View details such as images, names, descriptions, and prices.

- Add plants to a shopping cart.

- Manage cart items.

  

The project emphasized implementing interactive features such as a navigation bar, dynamically updating cart quantities, and calculating total costs as users added, removed, or adjusted item quantities.

  

The goal was to apply the skills learned in previous practice projects to build a functional, user-friendly e-commerce experience.

## Criterios de calificación

  

### Task 1 — README.md (2 points)

### Task 4 — App.jsx (3 points)

- A **Get Started** button.

  

### Task 5 — CartSlice.jsx (4 points)

  

Enviar the GitHub URL of the `CartSlice.jsx` file, which includes the code implementing the Redux slice for the shopping cart.

  

### Task 6 — ProductList.jsx (16 points)

  

Enviar the GitHub URL of the `ProductList.jsx` file.

  

The implementation must:

  

1. Display at least **six unique houseplants per category**, each with:

- Thumbnail.

- Name.

- Price.

2. Group the plants into at least **three categories**.

3. Include an **Add to Cart** button for each plant.

4. Add the selected product to the shopping cart.

5. Disable the **Add to Cart** button after the product is added.

6. Increment the cart icon count.

7. Include a navbar on both the **Product Listing** and **Cart** pages, with links to:

- Home.

- Plants.

- Cart.

8. Display a cart icon showing the **total number of items dynamically**.

  

### Task 7 — CartItem.jsx (23 points)

  

Enviar the GitHub URL of the `CartItem.jsx` file displaying the Shopping Cart page.

  

The implementation must:

  

1. Show the **total cart amount** of the plants.

2. Show the **total cost for each plant** in the cart.

3. Display for each plant:

- Thumbnail.

- Name.

- Unit price.

4. Include buttons to **increase and decrease quantity**, updating the cart correctly.

5. Include a **Delete** button for each item.

6. Include a **Checkout** button that shows **Coming Soon** or a similar message.

7. Include a **Continue Shopping** button linking back to the product listing page.
